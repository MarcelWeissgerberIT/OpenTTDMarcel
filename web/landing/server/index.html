Warum ein eigener Server?

Auf einem Server bauen mehrere Leute gleichzeitig in derselben Welt – jeder mit eigener Firma. Die Welt läuft weiter, auch wenn niemand zuschaut.

Wer einen Server betreibt, taucht automatisch bei allen Spielern im Menü auf. Du brauchst dafür keine Erlaubnis und musst niemanden fragen.

Was es kostet: etwa 3–5 € im Monat für einen kleinen Mietserver. Mehr braucht es nicht – das Spiel selbst ist frei.

Der schnelle Weg: Fly.io

Fly gibt dir eine fertige Adresse mit Verschlüsselung – das spart die ganze Zertifikats-Arbeit. Du brauchst ein Konto und das Programm flyctl.

  1. Anmelden: fly auth login
  2. App anlegen (Name frei wählbar, muss weltweit einmalig sein): 
    fly apps create mein-ottd-server
  3. Platz für die Spielstände: 
    fly volumes create ottd_data --app mein-ottd-server --region fra --size 1 --yes
  4. Angaben für die Serverliste hinterlegen: 
    fly secrets set --app mein-ottd-server \
  OTTD_PUBLIC_HOST=mein-ottd-server.fly.dev \
  OTTD_SERVER_NAME="Meine Welt" \
  OTTD_SERVER_NOTE="Gemütlich, keine Abrisse" \
  OTTD_ANNOUNCE_KEY="$(openssl rand -hex 16)"
  5. Server starten: 
    fly deploy --app mein-ottd-server \
  --image ghcr.io/marcelweissgerberit/openttdmarcel-server:latest \
  --vm-memory 512

Fertig. Nach ein paar Minuten steht dein Server in der Liste oben – und im Spiel bei allen anderen.

Wichtig: Der Server muss durchgehend laufen. Stell in Fly sicher, dass die Maschine nicht schlafen gelegt wird (auto_stop_machines = false), sonst friert deine Welt ein, sobald niemand spielt.
Eigener Rechner oder Mietserver (Docker)

Auf jedem Linux-Server mit Docker:

docker run -d --name ottd --restart unless-stopped \
  -p 8080:8080 -v ottd_data:/data \
  -e OTTD_PUBLIC_HOST=ottd.deine-domain.de \
  -e OTTD_SERVER_NAME="Meine Welt" \
  -e OTTD_ANNOUNCE_KEY="ein-langes-geheimnis" \
  ghcr.io/marcelweissgerberit/openttdmarcel-server:latest

Davor gehört ein Reverse-Proxy mit Verschlüsselung, zum Beispiel Caddy – zwei Zeilen genügen:

ottd.deine-domain.de {
    reverse_proxy 127.0.0.1:8080
}
Warum Verschlüsselung Pflicht ist: Das Spiel läuft im Browser über https, und von dort darf nur eine verschlüsselte Verbindung aufgebaut werden. Ohne Zertifikat kommt niemand auf deinen Server.
Einstellungen deiner Welt

Die Konfiguration liegt im Datenverzeichnis unter /data/openttd.cfg. Ändern, Server neu starten, fertig.

EinstellungBedeutung
server_nameName im Spiel (die Liste nimmt OTTD_SERVER_NAME)
max_clientsWie viele gleichzeitig mitspielen dürfen
max_companiesWie viele Firmen es geben darf
autoclean_unprotectedNach wie vielen Monaten verwaiste Firmen verschwinden

Welt sichern und weiterspielen

Der Server sichert monatlich nach /data/save/autosave und spielt beim Start den neuesten Stand weiter. Für eine frische Welt einfach den Ordner leeren und neu starten.

Wenn niemand hereinkommt

„Der Server läuft eine andere Version"

Das ist der häufigste Fall. Server und Browser-Fassung müssen aus demselben Stand gebaut sein. Nach einem Spiel-Update also das Bild neu holen:

fly deploy --app mein-ottd-server \
  --image ghcr.io/marcelweissgerberit/openttdmarcel-server:latest

Die Liste blendet Server mit abweichender Version automatisch aus – dann bist du für andere unsichtbar, obwohl der Server läuft.

Server steht nicht in der Liste

  • Sind OTTD_PUBLIC_HOST und OTTD_ANNOUNCE_KEY gesetzt? Ohne beides bleibt der Server absichtlich privat.
  • Ist die Adresse von außen erreichbar und verschlüsselt?
  • Der Eintrag verschwindet nach etwa 12 Minuten ohne Lebenszeichen – läuft der Server noch?

Beitritt bricht sofort ab

Prüfe, ob der Reverse-Proxy WebSocket-Verbindungen durchlässt. Caddy und Fly tun das von sich aus, nginx braucht die passenden Kopfzeilen.

Deinen Server bekannt machen
  • Im Spiel: Du stehst automatisch im Mehrspieler-Menü aller Spieler – der wichtigste Platz, und du musst nichts tun.
  • Beschreibung nutzen: OTTD_SERVER_NOTE erscheint in der Liste. Schreib rein, was deinen Server ausmacht – „Anfängerfreundlich", „Nur Eisenbahn", „Jeden Sonntag neue Welt".
  • Welt teilen: Zeig, was auf deinem Server gebaut wurde – im Spiel über das Disketten-Menü → „Welt teilen (Link)". Wer den Link öffnet, sieht deine Welt sofort im Browser.
  • Diese Seite verlinken: Sie zeigt oben immer die gerade laufenden Server.
Verstößt jemand gegen die guten Sitten, kann ein Eintrag gesperrt werden. Sonst ist die Liste offen für alle.
